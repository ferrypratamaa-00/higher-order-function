


> # JavaScript Practice Roadmap
>
> Project ini adalah simulasi real-case untuk latihan JavaScript, Materi disusun bertahap mulai dari `filter()`, `map()`, dan lainnya — dengan struktur folder terpisah untuk setiap topik.  
> Setiap bagian ditutup dengan sesi `recap/` sebagai review menyeluruh, guna memperkuat pemahaman.
>
> 💻 Cocok buat kamu yang belajar JavaScript dan pengen latihan sambil nyimulasikan workflow pengembangan software profesional.
